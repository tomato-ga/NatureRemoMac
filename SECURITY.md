# Security policy

## Reporting a vulnerability

Use GitHub's **Security → Report a vulnerability** flow when private
vulnerability reporting is available for the repository. Do not disclose a
vulnerability or credential in a public issue.

If private reporting is not yet available, open a public issue containing only
a request for a private contact channel. Do not include reproduction details,
account data, device identifiers, or access tokens in that issue.

## Exposed Nature Remo tokens

If a token is pasted into an issue, commit, log, or screenshot, revoke it
immediately at [Nature Home](https://home.nature.global/) and create a new one.
Deleting a public message or rewriting Git history is not sufficient because
copies and caches may still exist.

## Supported versions

Security fixes are applied to the latest commit on the default branch until
versioned source releases are established.

## 日本語

脆弱性はGitHubの **Security → Report a vulnerability** から非公開で報告してください。
公開Issueに再現手順、アカウント情報、デバイスID、アクセストークンを書かないでください。

トークンを公開してしまった場合は、投稿の削除だけで済ませず、
[Nature Home](https://home.nature.global/)から直ちに失効させて再発行してください。
